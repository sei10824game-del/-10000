# RL Clones（強化学習クローン）— Minecraft 1.20.1 Forge

プレイヤーのクローンを召喚するMODです。クローンは強化学習で行動を学習し、自分の目で見たものだけを認識します。ほかのクローンやプレイヤーの行動を見て学ぶこともでき、敵の種類ごとに戦い方を身につけます。

## 操作

| キー | 動作 |
|---|---|
| **Z** | 目の前にクローンを召喚（スポーンエッグでも召喚可） |
| **X** | 全クローンの強化学習をリンク / 解除（ON: 全員で1つの脳を共有 / OFF: 各自が脳のコピーで学習を継続） |
| **P** | クローンのリスポーン ON / OFF（OFFのとき、死んだクローンは消滅） |

* キーはオプション →「操作設定」→「RLクローン」から変更できます。
* P はバニラの「ソーシャル設定」キーと重なっているため、初回起動時にバニラ側の割り当てを自動で解除します（チャットで通知されます）。
* **クローンのスポーンエッグ**はクリエイティブの「スポーンエッグ」タブにあります。ブロックに使うとクローンを召喚します。

## クローンの仕様

### プレイヤーと同じ存在
クローンの実体は本物の `ServerPlayer` です。そのため、体力・満腹度・リーチ（3ブロック）・攻撃クールダウン・クリティカル・ダッシュ攻撃・採掘速度・アイテムの拾得・防具・死亡ドロップ・実績・統計など、すべてがプレイヤーと同じルールで動きます。移動の入力（WASD / ジャンプ / ダッシュ / スニーク / 視点移動）もプレイヤーと同じで、視点の回転速度にも上限があります。

* プレイヤーのスキンをコピーします。タブリストには `[AI] Clone1` のように表示されます。
* 所持品の中から最も強い武器を持ち、最も良い防具を装備し、盾はオフハンドに持ちます。
* 地面に落ちているアイテムは近くを通るだけで拾います。アイテムを渡したいときはクローンの近くに投げるか、**スニークしながら右クリック**でクローンの持ち物を開いて直接入れてください。

### 視覚（壁越しに見ることはできない）
* 視野角（水平102° / 垂直70°）、視認距離（48ブロック）、視線の遮り（レイキャスト）の3つで判定します。ガラス越しには見えますが、石壁越しには見えません。
* 暗い場所では見える距離が短くなります。盲目・暗闇のエフェクトも影響します。暗視を使えば遠くまで見えます。透明化したエンティティは、装備を身につけていなければ見えません。
* 見えなくなったものも約10秒間は位置を記憶します。
* 見えない相手から攻撃を受けたときは、プレイヤーと同じようにその方向へ振り向きます。

### 強化学習
* **戦闘（敵の種類ごとのQテーブル）**：`minecraft:zombie`・`minecraft:skeleton` など、エンティティの種類ごとに別々のQテーブルで戦い方を学びます。
  * 状態は、学習した敵のリーチを基準にした距離帯、自分の攻撃チャージ、学習した敵の攻撃クールダウンを基準にした敵の攻撃準備状態、自分の体力、敵の溜め動作（クリーパーの着火・弓を引く動作など）、周囲の敵の数、高低差です。
  * 行動は、接近・攻撃・ジャンプクリティカル・ダッシュ攻撃・後退・左右ステップ・盾ガード・待機・弓射撃・足場積み（ピラー）の11種類です。
  * 報酬は、与ダメージ（＋）、撃破（＋）、被ダメージ（－）、死亡（－）、盾で防いだダメージ（＋）です。
* **行動方針（戦略Qテーブル）**：戦う・逃げる・食べる・アイテムを拾う・仲間に付いて行く・探索する・木を切る・鉱石を掘る・狩る・休む（周囲を見回す）の中から、状況に応じて選びます（SMDP Q学習）。
* 経験リプレイで学習効率を上げています。学習はオフポリシーのQ学習なので、他者を観察して得た経験もそのまま学習データとして使えます。

### 敵ごとの知識（視覚による観察で学習）
敵が誰かを攻撃する場面を**実際に見たとき**に、以下を学習します。

* 近接攻撃のリーチ、攻撃のクールダウン（連続攻撃の間隔）、ダメージ
* 飛び道具の射程・発射間隔・ダメージ
* 爆発の半径・導火線の長さ・ダメージ
* 移動速度、敵対を始める距離、倒すまでに必要なダメージ量（推定体力）
* 特性：日光で燃える、壁を登る、飛ぶ、テレポートする、盾を無効化する、分裂する、先制攻撃してくる
* 付与される状態異常（毒・空腹など）

学習した知識は戦闘時の状態区分（距離帯・攻撃準備の判定）にそのまま使われます。

### 観察学習（模倣）
クローンは、視界内で活動しているクローンやプレイヤーの状況を**自分の状態空間に置き換え**ます。そのうえで、見えた行動（移動方向・攻撃・クリティカル・ガード・食事・採掘など）を推定し、同じ報酬関数で評価してQテーブルを更新します。プレイヤーとクローンは区別しません。うまくいった行動は探索時に優先して試します。

### リンク（Xキー）
* **ON**：全クローンのQテーブルと知識を、学習回数に応じた重み付き平均で統合し、全員が1つの脳を共有します。誰が経験しても全員の学習になります。リンク中に召喚したクローンもこの脳を共有します。
* **OFF**：統合された脳のコピーを各クローンが受け継ぎ、それぞれ個別に学習を続けます。

### リスポーン（Pキー）
* **ON**：死亡したクローンは、バニラのプレイヤーと同じ手順でリスポーンします（ベッド / リスポーンアンカー / ワールドスポーン）。脳（学習内容）はそのまま引き継ぎます。召喚時には、召喚したプレイヤーのリスポーン地点を引き継ぎます。
* **OFF**：死亡したクローンは約3秒後に完全に消滅します。消滅する前にPを押せばリスポーンできます。

### その他
* 木を切るのは、自然生成の葉（プレイヤーが置いた葉ではない）が近くにある原木だけです。原木で建てた家は壊しません。狩りの対象は牛・豚・鶏・羊・ウサギ・ムーシュルームの大人だけで、名札付きやリードでつながれた動物は狩りません。
* クローンがいても、実プレイヤー全員が寝れば夜をスキップできます（設定で変更可）。
* クローンと学習内容は `ワールド/rlclones/brains/` に保存されます。サーバーを再起動しても復元されます。

## コマンド `/rlclone`

| コマンド | 内容 |
|---|---|
| `/rlclone summon [数]` | クローンを召喚 |
| `/rlclone list` | 一覧（HP・満腹度・位置・現在の行動）と、リンク / リスポーンの状態 |
| `/rlclone remove <名前>\|all` | クローンを削除 |
| `/rlclone link [on\|off]` / `respawn [on\|off]` | X / P と同じ切り替え |
| `/rlclone ai <名前> on\|off` | 自律行動のON/OFF（OFFでも視界と観察学習は動き続けます） |
| `/rlclone brain <名前>` | 学習の統計（状態数・自己学習 / 模倣 / リプレイの更新回数・撃破数・死亡数）と、視覚の状態 |
| `/rlclone knowledge <名前> [エンティティID]` | 敵ごとに学習した知識と、距離帯ごとの最善行動 |
| `/rlclone save` | 脳を即時保存 |

## 設定（`config/rlclones-common.toml`）
クローンの最大数、OP限定にするかどうか、リスポーン / 消滅までの時間、視認距離・FOV・暗さによる視界の制限、学習率・割引率・探索率・模倣の重み・リプレイ回数、ブロックの破壊 / 設置の許可、夜のスキップ判定。

## ビルドとテスト
```
./gradlew build              # build/libs/rlclones-1.0.0.jar
./gradlew runGameTestServer  # 実サーバー上で受け入れテスト（GameTest）を実行
```
GitHub Actions でビルドとGameTestを自動で実行し、jarを成果物（artifact）としてアップロードします。

GameTest（`src/main/java/com/rlclones/gametest/CloneGameTests.java`）で確認している内容：
* クローンがプレイヤーリストに入った本物のプレイヤーであること（サバイバル・体力20・リーチ3・装備の自動選択）
* 視界：正面は見え、背後・石壁越しは見えず、ガラス越しは見えること。振り向くと見える対象が入れ替わること
* ハスクと戦って倒し、ハスク専用のQテーブルを学習すること
* 他者がハスクに攻撃される様子を見るだけで、ハスクのクールダウン（約20tick）と短いリーチを学習すること
* 他のクローンの戦闘を見るだけで、模倣学習の更新が発生すること
* プレイヤーと同じ速度で原木を採掘し、ドロップを拾うこと
* 脳の保存・読み込みと、重み付き統合が正しく動くこと
* Xで脳を共有 / 解除できること、リンク中に召喚したクローンも共有に加わること
* Zで召喚、Pでリスポーンを切り替えられること
* リスポーンONでは同じUUIDと同じ脳のまま復活し、OFFでは消滅すること
