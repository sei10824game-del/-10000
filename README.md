# RL Clones（強化学習クローン）— Minecraft 1.20.1 Forge

プレイヤーのクローンを召喚するMODです。クローンは強化学習で行動を学習し、自分の目で見たものだけを認識します。ほかのクローンやプレイヤーの行動を見て学ぶこともでき、敵の種類ごとに戦い方を身につけます。

## 操作

| キー | 動作 |
|---|---|
| **Z** | 目の前にクローンを召喚（スポーンエッグでも召喚可）。数の上限は初期設定でなし（設定 `maxClones`、0 = 無制限） |
| **X** | 全クローンの強化学習をリンク / 解除（ON: 全員で1つの脳を共有 / OFF: 各自が脳のコピーで学習を継続） |
| **P** | クローンのリスポーン ON / OFF（OFFのとき、死んだクローンは消滅） |
| **L** | 手に持っているブロックを「有害なブロック」として全クローンに教える（クローンは見つけ次第壊し、建材にも使わなくなる） |

* キーはオプション →「操作設定」→「RLクローン」から変更できます。
* P はバニラの「ソーシャル設定」キーと重なっているため、初回起動時にバニラ側の割り当てを自動で解除します（チャットで通知されます）。
* **クローンのスポーンエッグ**はクリエイティブの「スポーンエッグ」タブにあります。ブロックに使うとクローンを召喚します。

## クローンの仕様

### プレイヤーと同じ存在
クローンの実体は本物の `ServerPlayer` です。そのため、体力・満腹度・リーチ（3ブロック）・攻撃クールダウン・クリティカル・ダッシュ攻撃・採掘速度・アイテムの拾得・防具・死亡ドロップ・実績・統計など、すべてがプレイヤーと同じルールで動きます。移動の入力（WASD / ジャンプ / ダッシュ / スニーク / 視点移動）もプレイヤーと同じで、視点の回転速度にも上限があります。

* プレイヤーのスキンをコピーします。タブリストには `[AI] Clone1` のように表示されます。
* 所持品の中から最も強い武器を持ち、最も良い防具を装備し、盾はオフハンドに持ちます。
* 地面に落ちているアイテムは近くを通るだけで拾います。アイテムを渡したいときはクローンの近くに投げるか、**スニークしながら右クリック**でクローンの持ち物を開いて直接入れてください。

### 泳ぎ・落下・エリトラ
* 水中では常に浮上して泳ぎ、前進しながらジャンプすることで岸（1ブロックの段差）に上がります。水中の経路も辿れます。
* 落下ダメージはプレイヤーと同じ判定で受けます（落下中のクリティカル攻撃もプレイヤーと同じ条件で発生します）。
* エリトラを持っていれば、胸防具がないときは装着します。落下中（4ブロック以上）は自動で開いて滑空します。ロケット花火があれば、40ブロック以上離れた目的地へは地上から離陸して飛行し、目的地の近くで降下して着地します。着地後はチェストプレートに付け替えます。

### 聴覚
* プレイヤーのクライアントが受け取るのと同じ音（同じ聞こえる範囲）をクローンも受け取ります。視界の外や壁の向こうでモブの鳴き声・足音・被弾音が聞こえると、その声で種類を聞き分けて「そこに何かがいる」と記憶し、脅威として判断に使います。音のした方向にはプレイヤーのように振り向きます。
* クリーパーの着火音を聞くと、見えていなくても爆発が近いことに気付きます。

### クラフト・精錬（プレイヤーと同じUIを使用）
* 行動方針に「クラフト」があり、強化学習で選ばれます。インベントリの2×2グリッド、作業台の画面、かまどの画面を実際に開いて操作します。材料はレシピブックで配置し（レシピをクリックしたときと同じ動作）、完成品はシフトクリックで取り出します。
* 原木→板材→作業台→棒→剣・ツルハシ・斧、鉄があれば盾・鉄防具、丸石が8個あればかまど、という順で、今の装備より良くなるものだけを作ります。作業台やかまどが近くになければ地面に設置します。
* 原石（鉄・金）や生肉はかまどに入れ（燃料は石炭・木炭・板材など）、焼き上がる頃に戻って取り出します。
* 他のクローンやプレイヤーがクラフトする様子も観察学習の対象です。

### 武器（バニラ・MOD共通）
* 近接武器は攻撃力の属性（ATTACK_DAMAGE）で比べるため、MODの剣や斧もそのまま最適な武器として選びます。
* 遠距離武器は、クラスまたは使用アニメーションから操作方法を判別します。弓型（引き絞って放す）、クロスボウ型（装填してから右クリックで発射）、投擲型（トライデントや槍：構えて投げる）の3種類です。MODの弓・クロスボウ・槍も同じ扱いで、弾速に合わせて偏差射撃と放物線の補正をします。
* 投げたトライデントや拾える矢は、アイテムと同じように回収します。
* 右クリックに独自の機能を持つ武器（MODのスキル付きの剣、銃、杖、投擲武器など）は「特殊武器を使う」行動で試し、どの敵に効くかを敵の種類ごとに学習します。

### 穴からの脱出
* 歩いて出られる範囲が極端に狭い状態（穴にはまった・壁に囲まれた）を自動で検出し、ほかの行動より優先して脱出します。
* ブロックを持っていれば真上に積んで登り、なければ階段状に掘って登ります（目的地が同じ高さなら横に掘り進めます）。高い柱の上に取り残されたときは足元を掘って降ります。
* 掘った先に溶岩や水が流れ込む場所、岩盤は避けます。脱出できないときはチャットで助けを呼びます。

### チャット（緊急連絡・応援要請）
* 緊急事態になると、座標と理由をチャットに流します（例：`<Clone3> 【緊急】X:120 Y:64 Z:-35 溶岩で燃えている`）。理由は、溶岩・炎上・溺れそう・クリーパーが爆発寸前・体力が少ない（攻撃している敵の種類つき）・穴から出られない、です。
* 敵が3体以上いるときや敵が強すぎるときは、敵の内訳つきで応援を呼びます（例：`【応援求む】… 敵が多すぎる（ゾンビ×3, スケルトン×1）`）。食料がないときも同様です。
* 他のクローンはチャットを読み、要請を記憶します。行動方針の「救援」を選ぶと、その座標へ駆けつけます（向かうときに返事をします）。救援するかどうかも強化学習で決まり、駆けつけると報酬が入ります。
* プレイヤーのチャットも読みます。「助けて 120 64 -35」「help」「応援」「来て」などが対象で、座標がなければ発言者の位置へ向かいます。
* **呼ぶ人数は状況で決めます**：敵の数（敵1体につき1人、瀕死なら+1）、敵の強さ（敵の合計体力と自分の体力・攻撃力の比）、体力低下（敵2体以上なら2人）など。すでに近くにいる仲間の数は差し引きます。メッセージに人数が入ります（例：`【応援求む】… 敵が多すぎる（ハスク×5）（4人求む）`）。プレイヤーの「3人来て」も読み取ります。後から敵が増えて状況が悪化したら、待たずに人数を増やして呼び直します。
* 駆けつけるクローンは `向かう` と返事をし、他のクローンはその数を数えます。**必要人数がすでに向かっていれば、残りは行きません。**
* **解決したら報告します**：危険な状態が終わると `【解決】X:… の件は解決した。もう来なくて大丈夫！` と流し、向かっていたクローンは引き返します。やられた場合は「取消」を流します。プレイヤーの「解決」「もう大丈夫」「助かった」なども理解します。

### 有害なブロック（マグマブロック・MODの感染ブロックなど）
* 攻撃者のいないダメージを受けると、原因のブロックを突き止めて「有害」と学習します。マグマブロック・サボテン・スイートベリー・焚き火・粉雪・鍾乳石はダメージの種類から即座に特定します。
* 感染MODのような未知のダメージは、**ダメージを受けたときに毎回触れていて、無傷で立っていたことがほとんどないブロック**を犯人と判断します（3回以上の証拠が必要なので、石や土を誤って有害扱いしません）。
* 有害と学習したブロックが視界に入ると、近くに敵がいないときに壊しに行きます（適した道具を使用・溶岩の隣や足元が抜ける場所は避ける・1分間に16個まで）。建築や足場の材料としても使いません。
* 近くに（見えている範囲で16ブロック以内）そのブロックを知らないクローンがいると、チャットで名前を挙げて教え（`気をつけて、マグマブロック は有害なブロックだ！（Clone2）`）、相手はそれを学習します。有害ブロックの知識は脳と一緒に保存されます。

### チェスト・拠点
* **野良チェストを漁ります**：ダンジョン・村・難破船などの生成チェスト（ルートテーブル付き、または構造物内）を見つけると、開けて中身を取り出します。
* **使わない物がたまると拠点を作ります**：その時点で使えない物（余った同種の武器・防具・道具、2スタック目以降の種、食べられない物、64個を超える木材、128個を超えるブロック、弓がないときの矢、ガラクタ）が5枠以上、または空きが少ないときに行動方針「保管」が選べます。
  * 近く（96ブロック以内）に誰かの拠点があれば、それを自分の拠点として使います（他のクローンのチェストも自由に使います）。
  * なければ、村の簡素な家を真似た5×5の小屋（2段の壁・原木の柱・入口・平らな屋根、55ブロック）を建てて拠点にします。材料が足りないときはチェストだけを置いた簡易拠点にします。
  * チェストはクラフトUIで作って小屋の中に置き、不要な物を入れます。いっぱいになったらチェストを追加します。
* **必要になったら取り出します**：拠点のチェストに今より良い武器・防具、盾、ツルハシ（持っていない時）、食料（空腹で持っていない時）、ブロック（足りない時）があれば、行動方針「回収」で取りに行きます。どのチェストに何があるかは全クローンで共有しています（ワールドに保存）。
* チェストから取り出す・入れる・漁るたびに、**座標とアイテムをチャットに流します**（例：`拠点チェスト X:10 Y:64 Z:20 に納品した: 骨×3, 糸×4`）。

### 農業
* 水の近く（4ブロック以内）に土・草ブロックがあり、クワと種を持っていれば、クワで耕して種を植えます。実った作物は収穫して植え直します。種を持っていてクワがなければ、木のクワをクラフトします。

### 好奇心とアイテムの知識
* ブロックは**壊しただけでも**理解します。何が落ちるか（何も落ちないか）、どの道具が速いか、適した道具がないと何も落とさないか、などを知り、回収できるものは拾います。
* **未知のブロック**：見たことのない（掘ったことも持ったこともない）ブロックで、今の道具で入手できるものを見つけると、掘って持ち帰ります（拠点の近く・チェスト等の機能ブロック・ドア・ベッド・作物は対象外）。
* **手に入れたアイテムを理解します**：新しいアイテムを手に入れると、その紹介をチャットに流します（例：`【発見】干し草の俵 を手に入れた: 小麦が作れる（さらにパン, クッキーが作れる） / 完全ブロック：この上に敵が湧く`）。
  * 理解する内容：作れる物（2段先まで）、焼くと何になるか、燃料になるか（何個分）、食べられるか（満腹度・副作用）、敵が湧くブロックか／湧かないブロックか、光るか、落下するか、植えられるか、有害か、攻撃力・防御力、ポーションの効果と時間。
* **伝達**：特殊な情報（用途・食料・燃料・光・ポーション効果など）があるアイテムは、近く（見えている16ブロック以内）のそれを知らないクローンにチャットで名前を挙げて教えます。2個以上持っていて相手が5ブロック以内なら、1個投げて渡します。
* **未知のアイテムを作ります**：今まで持ったことのないアイテムがクラフトできるなら、積極的に作って調べます（ダイヤ・エメラルド・ネザライト・エンダーパール・ブレイズロッド・トーテムなど貴重品や、道具・かまど用に必要な棒・丸石・板材・鉄は使いません）。

### 見回し
* 立ち止まって辺りを見回すときの回転速度（3〜32°/tick）をクローン自身が選びます。見回しの結果（新しく気付いた物の数／秒）を報酬として、状況（暗い／敵がいた直後）ごとに最適な速度を学習します。上下にも視線を動かします。

### 石器時代・かまど・醸造
* ツルハシを持っていて、石の道具・かまど・醸造台に丸石が足りないときは、石を掘って丸石を集めます（行動方針「採石」）。
* 丸石が8個あればかまどを作り、持っているかまどは設置します。醸造台も同様です。
* **醸造**：ブレイズロッドと丸石があれば醸造台を作ります（近くに醸造台があれば作らず、それを使い、ロッドはブレイズパウダーにします）。空き瓶があれば水を汲み、燃料・瓶・材料を入れて醸造し、出来上がったら取り出しに戻ります。**作ったことのないポーションが作れる限り作り続け**、手に入れるとその効果を理解します。
* **ポーションの使用**：理解した効果を状況に合わせて使います。体力4割以下で治癒・再生、燃えているとき耐火、水中で息が続かないとき水中呼吸、戦闘開始時に力・俊敏・耐性、暗い場所で暗視。投げるポーション（負傷・毒・弱体化・鈍化）は戦闘中の敵に投げます。

### アイテムの扱い
* **不死のトーテム**：体力が3割（または6）以下になると左手（オフハンド）に持ち替えます。回復したら盾に戻します。
* **エンダーパール**：ブロックがなく壁を掘れない穴にはまったときや、瀕死で敵に詰め寄られて逃げるとき、着地点を弾道計算して投げます。
* **バケツ**：
  * 高所から落ちているときは着地直前に水を置いて落下ダメージを防ぎ（MLG）、着地後に水を回収します。
  * 燃えているときは足元に水を置いて消火し、回収します。
  * 空のバケツは近くの水源で水を汲み、2つ目のバケツで牛の乳を搾ります。
  * 毒・衰弱・空腹などの悪い効果を受けたら牛乳を飲みます。
  * 溶岩バケツは他に燃料がないときのかまどの燃料にします。鉄が3個あればバケツを作ります。

### 足元の安全（しゃがみ）
* 進む先に落ちたら死ぬ段差（体力に応じて4〜5ブロック以上、または溶岩・マグマ・サボテンなど）があると、クローンは自分の判断でしゃがみます。しゃがんでいる間はプレイヤーと同じく縁から落ちません。橋を架けるときも縁ではしゃがみます。

### 落下への備え
* 落下中は自分の軌道（落下速度・横移動・空気抵抗）から着地点を予測し、そこへ水バケツ・スライムブロック・干し草の俵・粉雪バケツ・クモの巣の順で置きます（予測なので外れることもあります）。水や干し草は着地後に回収します。

### 移動（橋・エンダーパール・潜水）
* 遠くへ行く途中で、穴・溶岩・水で道が切れて先へ進めないと、不要なブロック（なければ木材以外の建材）で橋を架けて渡ります。
* 架ける材料がないときは、着地点を計算して対岸へエンダーパールを投げます。体力が7より多いときだけ使い（パールのダメージは5）、敵から逃げるとき・穴から出るときも同じ条件です。
* 水中では、目的地や獲物が下にあれば潜ります（息が3割を切ると浮上します）。魚も食料として狩ります。

### 動物
* **テイム**：オオカミ（骨）・ネコ（生魚）・オウム（種）が近くにいて、そのアイテムを持っていればテイムします。
* **繁殖**：自分がテイムした動物や柵の中のニワトリが繁殖できる状態で、餌（オオカミなら肉、ニワトリなら種）を2つ以上持っていれば与えます。
* **ニワトリの柵**：木材が余っていて（板材換算40枚以上）卵を持っていると、柵とフェンスゲートを作り、村にあるような5×5の囲いを建てます。中に卵を投げてから外に出てゲートを閉めます。後から手に入れた卵も、中に入って投げます。
* 柵の中の動物は最低2羽残し、それより多いときだけ空腹時に倒して食べます。テイムした動物は食べません。

### 道具・武器
* クワ：種を持っていてクワがないときは、他の道具より先に木のクワを作ります。
* 弓（糸3＋棒3）と矢（火打石＋棒＋羽）、釣り竿（糸2＋棒3）を作ります。
* **釣り**：見える水辺で釣り竿を投げ、浮きが沈む音（プレイヤーと同じく音で分かる）で引き上げます。食料が少ないと釣りを選びやすくなります。
* **TNT**：火薬5＋砂4で作り、TNTの数だけボタンも作ります。敵が3体以上固まっているとき、近く（10ブロック）にクローン・プレイヤー・ペット・村人がいなくて拠点や柵からも離れていれば、敵の方向にTNTを置き、ボタンを付けて押し、逃げます。
* **溶岩バケツ**：戦闘中、敵の足元に溶岩を流します。周囲5ブロックに味方・ペット・村人がいるとき、拠点の近く、燃えやすいブロックの近く、自分から3ブロック未満のときは使いません。少し燃やしたら必ず回収します。

### 木材の調達
* 原木も木材も持っておらず、周りに木もないときは、建物などに使われている板材や原木を壊して手に入れます。拠点のブロック（拠点から12ブロック以内）は壊しません。

### 畑
* 種がないときは草（草・背の高い草・シダ）を刈って小麦の種を集めます。水から4ブロック以内の土なら、崖でもどこでも耕して植えます。

### ボート
* 泳いでいる時間が長いとボートを作ります。水中を長く進む必要があるとき、ボートを水面に置いて乗り、目的地へ漕ぎ、岸で降りてボートを壊して回収します。
* 泳いでいる最中・水の上ではクラフト（作業台の設置）をしません（作業台を持ったまま海に浮き続ける問題の修正）。

### 遠征（未開拓地へ集団で向かう）
* **討伐**：遠くに強い敵（体力60以上のボス級）や敵の群れ（5体以上）を見つけると、それを倒すための遠征を呼びかけます（`【討伐】… ラヴェジャー を倒しに行く`）。必要人数は敵の合計体力と自分の強さから決めます。現地で戦い、敵がいなくなると「討伐完了」で解散します。
* 行ったことのない場所（120〜200ブロック先の未踏のチャンク）を目指すとき、リーダーは**必要な人数を自分で決め**（夜・装備の弱さ・距離・これまでの死亡数で1〜4人）、今いる場所を集合地点としてチャットで呼びかけます（`【集合】X:… に集合！未開拓地（X:… Z:…）へ向かう。2人来てほしい`）。
* 呼びかけを読んだクローンは、必要人数に達していなければ「参加する」と返事をして集合地点へ向かいます。人数がそろうと出発し、**目的を達成するまで参加者はリーダーについて行きます**（途中で戦っても、戦闘が終われば同行に戻ります）。リーダーは遅れた仲間を待ち、目的地を見て回ったら「遠征完了、解散」と流します。
* プレイヤーも「参加」「join」と答えれば参加者に数えられます。

### サーバーの人数上限
* クローンはサーバーの最大人数に数えません（クローンの人数分だけ上限を自動で引き上げます）。クローンを大量に出したワールドを開き直しても「サーバーが満員」にはなりません。
* クローン数の上限は標準で無制限です。古い設定ファイルに `maxClones = 16` などが残っている場合は、`/rlclone limit unlimited`（または `/rlclone limit <数>`）でゲーム内から変更できます（設定ファイルにも保存されます）。

### 盾
* 盾はオフハンドに持ちます（トーテム以外のオフハンドのアイテムとは入れ替えます）。戦闘を始めるときにも装備を確認します。
* 敵が攻撃できる距離にいて、自分がまだ反撃できないときや、敵が弓を引いているときには、盾を構える行動を初期値から優先します。盾を構えたまま前進もします。

### 視覚（壁越しに見ることはできない）
* 視野角（水平102° / 垂直70°）、視認距離（48ブロック）、視線の遮り（レイキャスト）の3つで判定します。ガラス越しには見えますが、石壁越しには見えません。
* 暗い場所では見える距離が短くなります。盲目・暗闇のエフェクトも影響します。暗視を使えば遠くまで見えます。透明化したエンティティは、装備を身につけていなければ見えません。
* 見えなくなったものも約10秒間は位置を記憶します。
* 見えない相手から攻撃を受けたときは、プレイヤーと同じようにその方向へ振り向きます。

### 強化学習
* **戦闘（敵の種類ごとのQテーブル）**：`minecraft:zombie`・`minecraft:skeleton` など、エンティティの種類ごとに別々のQテーブルで戦い方を学びます。
  * 状態は、学習した敵のリーチを基準にした距離帯、自分の攻撃チャージ、学習した敵の攻撃クールダウンを基準にした敵の攻撃準備状態、自分の体力、敵の溜め動作（クリーパーの着火・弓を引く動作など）、周囲の敵の数、高低差です。
  * 行動は、接近・攻撃・ジャンプクリティカル・ダッシュ攻撃・後退・左右ステップ・盾ガード・待機・弓射撃・足場積み（ピラー）の11種類です。
  * 報酬は、与ダメージ（＋）、撃破（＋）、被ダメージ（－）、死亡（－）、盾で防いだダメージ（＋）です。
* **行動方針（戦略Qテーブル）**：戦う・逃げる・食べる・アイテムを拾う・仲間に付いて行く・探索する・木を切る・鉱石を掘る・狩る・休む（周囲を見回す）の中から、状況に応じて選びます（SMDP Q学習）。
* 経験リプレイで学習効率を上げています。学習はオフポリシーのQ学習なので、他者を観察して得た経験もそのまま学習データとして使えます。

### 敵ごとの知識（視覚による観察で学習）
敵が誰かを攻撃する場面を**実際に見たとき**に、以下を学習します。

* 近接攻撃のリーチ、攻撃のクールダウン（連続攻撃の間隔）、ダメージ
* 飛び道具の射程・発射間隔・ダメージ
* 爆発の半径・導火線の長さ・ダメージ
* 移動速度、敵対を始める距離、倒すまでに必要なダメージ量（推定体力）
* 特性：日光で燃える、壁を登る、飛ぶ、テレポートする、盾を無効化する、分裂する、先制攻撃してくる
* 付与される状態異常（毒・空腹など）

学習した知識は戦闘時の状態区分（距離帯・攻撃準備の判定）にそのまま使われます。

### 観察学習（模倣）
クローンは、視界内で活動しているクローンやプレイヤーの状況を**自分の状態空間に置き換え**ます。そのうえで、見えた行動（移動方向・攻撃・クリティカル・ガード・食事・採掘など）を推定し、同じ報酬関数で評価してQテーブルを更新します。プレイヤーとクローンは区別しません。うまくいった行動は探索時に優先して試します。

### リンク（Xキー）
* **ON**：全クローンのQテーブルと知識を、学習回数に応じた重み付き平均で統合し、全員が1つの脳を共有します。誰が経験しても全員の学習になります。リンク中に召喚したクローンもこの脳を共有します。
* **OFF**：統合された脳のコピーを各クローンが受け継ぎ、それぞれ個別に学習を続けます。

### リスポーン（Pキー）
* **ON**：死亡したクローンは、バニラのプレイヤーと同じ手順でリスポーンします（ベッド / リスポーンアンカー / ワールドスポーン）。脳（学習内容）はそのまま引き継ぎます。召喚時には、召喚したプレイヤーのリスポーン地点を引き継ぎます。
* **OFF**：死亡したクローンは約3秒後に完全に消滅します。消滅する前にPを押せばリスポーンできます。

### その他
* 木を切るのは、自然生成の葉（プレイヤーが置いた葉ではない）が近くにある原木だけです。原木で建てた家は壊しません。狩りの対象は牛・豚・鶏・羊・ウサギ・ムーシュルームの大人だけで、名札付きやリードでつながれた動物は狩りません。
* クローンがいても、実プレイヤー全員が寝れば夜をスキップできます（設定で変更可）。
* クローンと学習内容は `ワールド/rlclones/brains/` に保存されます。サーバーを再起動しても復元されます。

## コマンド `/rlclone`

| コマンド | 内容 |
|---|---|
| `/rlclone summon [数]` | クローンを召喚 |
| `/rlclone list` | 一覧（HP・満腹度・位置・現在の行動）と、リンク / リスポーンの状態 |
| `/rlclone remove <名前>\|all` | クローンを削除 |
| `/rlclone link [on\|off]` / `respawn [on\|off]` | X / P と同じ切り替え |
| `/rlclone ai <名前> on\|off` | 自律行動のON/OFF（OFFでも視界と観察学習は動き続けます） |
| `/rlclone brain <名前>` | 学習の統計（状態数・自己学習 / 模倣 / リプレイの更新回数・撃破数・死亡数）と、視覚の状態 |
| `/rlclone knowledge <名前> [エンティティID]` | 敵ごとに学習した知識と、距離帯ごとの最善行動 |
| `/rlclone save` | 脳を即時保存 |
| `/rlclone limit [<数>\|unlimited]` | クローン数の上限を表示 / 変更（0 または unlimited で無制限、OP権限） |

## 設定（`config/rlclones-common.toml`）
クローンの最大数、OP限定にするかどうか、リスポーン / 消滅までの時間、視認距離・FOV・暗さによる視界の制限、学習率・割引率・探索率・模倣の重み・リプレイ回数、ブロックの破壊 / 設置の許可、夜のスキップ判定。

## ビルドとテスト
```
./gradlew build              # build/libs/rlclones-1.0.0.jar
./gradlew runGameTestServer  # 実サーバー上で受け入れテスト（GameTest）を実行
```

GitHub Actions でビルドとGameTestを自動で実行し、jarを成果物（artifact `rlclones-jar`）としてアップロードします。あわせて、仮想ディスプレイ上でクライアントを起動し、タイトル画面まで到達することとZ/X/Pキーが登録されていることも確認しています（`client-smoke` ジョブ）。
